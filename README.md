# HR-Analytics-Data-Engineering
HR Analytics ETL pipeline using PySpark and Databricks with Bronze-Silver-Gold architecture, data cleaning, business KPI transformations, and Databricks Workflows.

# Dataset

The project uses three HR datasets:

Dataset	Description
Employee_Master.csv	Employee demographic and organizational information
Employment_Status.csv	Hiring, termination, attendance, and employment status
Compensation_Performance.csv	Salary, performance, engagement, and project details
